
# ⚽ PlaySpace Live

### More play. Less searching.

PlaySpace Live is a community-powered web application prototype that helps people discover play spaces, check listed time slots, and share available areas with their neighbourhood.

## Problem Statement

In crowded cities, children and families may struggle to find places to play. People often don't know when nearby grounds, courts, parks, or open spaces are available.

## Our Solution

PlaySpace Live provides a simple platform where people can explore shared play spaces and contribute information about free time slots.

## Features

- Search by place name or neighbourhood
- Filter by space type
- Filter by availability
- Add new space listings
- Save listings in browser local storage
- Share listings using supported browser features
- Request browser notification permission
- Responsive design for desktop and mobile

## Technology Stack

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- GitHub Pages

## Run Locally

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. For the best experience, use a local web server such as VS Code Live Server.

## Deployment

This project can be hosted using GitHub Pages.

Repository Settings → Pages → Deploy from a branch → `main` → `/(root)`.

## Current Limitations

This is a front-end hackathon MVP. Sample listings are not verified real locations or live availability information. New listings are stored in the current browser and do not sync across devices. Notification permission is demonstrated, but real-time alerts are not implemented.

## Future Improvements

- Shared database using Firebase or Supabase
- Map integration and location-based discovery
- Verified locations and time slots
- Real-time notifications
- Reporting and community moderation

## Hackathon Goal

Make local play spaces easier to discover and encourage communities to share available spaces responsibly.
